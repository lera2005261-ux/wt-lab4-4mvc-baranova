# WT-4 ASP.NET Core MVC

Веб-приложение «Интернет-магазин электроники» (вариант 1) на ASP.NET Core MVC (.NET 8).
Данные хранятся в памяти приложения, база данных не используется.

## Репозиторий

https://github.com/lera2005261-ux/wt-lab4-4mvc-baranova

## Опубликованное приложение

https://ИМЯ-ПРИЛОЖЕНИЯ.onrender.com

## Возможности

- главная страница с описанием системы;
- каталог товаров (Bootstrap-карточки), страница товара `/Product/Details/1`, 404 для несуществующего товара;
- добавление товара (GET/POST, валидация, сообщения об ошибках);
- редактирование и удаление товара;
- цена вводится с точкой (например, 2500.50);
- общий стиль через `Views/Shared/_Layout.cshtml`.

## Запуск локально

```
dotnet run
```

Приложение откроется на http://localhost:10000

## Запуск в Docker

```
docker build -t wt-lab4 .
docker run -p 10000:10000 wt-lab4
```

## Публикация на Render

Web Service → Language: Docker → Branch: main. Приложение слушает `0.0.0.0` и порт из переменной `PORT` (по умолчанию 10000).
